Mistkeep est **multi-campagne** : un même serveur héberge plusieurs tables,
chacune avec ses fiches, ses scènes, son chat, son combat et son journal —
totalement cloisonnées. Et chaque campagne joue avec **son** système de jeu.

## Le gestionnaire de campagnes

Le bouton **🏰** de l'en-tête ouvre le gestionnaire :

- **Basculer** d'une campagne à l'autre (l'application se recharge sur la
  campagne choisie) ;
- **Créer** une campagne : un nom + un système de jeu. Le créateur en devient
  propriétaire **et MJ** ;
- **👥 Gérer les membres** : ajouter ou retirer des comptes, choisir leur rôle
  (MJ ou joueur) *pour cette campagne* ;
- **🔗 Code d'invitation** : partagez un code pour que vos joueurs rejoignent
  la campagne **en libre-service**, sans intervention manuelle du MJ ;
- **📤 Exporter / 📥 Importer** : sauvegardez une campagne complète dans un
  **unique fichier JSON**, ou réimportez-la (transfert entre serveurs,
  sauvegarde) ;
- **🗑 Supprimer** une campagne dont on est propriétaire (définitif : toutes
  ses données sont effacées ; la campagne active et la campagne d'origine sont
  protégées).

<Tip>
  Les rôles sont **par campagne** : le même compte peut être MJ de sa table et
  simple joueur ailleurs. L'autorisation est appliquée côté serveur (le rôle
  affiché n'est pas qu'un habillage).
</Tip>

## Une campagne = un système

Le système choisi à la création détermine la fiche de personnage, les jets et
les calculs de toute la campagne :

| Système | Fiche | Particularités |
|---|---|---|
| **D&D 5e (2014)** | complète (SRD 5.1) | sélecteurs race/classe/historique, gabarits ⚙ (sauvegardes, emplacements, PV), multiclassage, montée de niveau |
| **D&D 5e (2024)** | complète (SRD 5.2) | **espèces** sans bonus de caracs (portés par les historiques en +2/+1), Maîtrise d'armes, aptitudes de classe et de sous-classe (résumés), sous-classes toutes au niveau 3 |
| **Pathfinder 2e** | Remaster à **rangs** | ascendances et classes Player Core (PV, vitesse, vision, rangs de Perception/sauvegardes appliqués via ⚙) ; maîtrise Qualifié/Expert/Maître/Légendaire (+2 par rang **+ niveau**), sauvegardes Vigueur/Réflexes/Volonté + Perception — un clic sur la pastille fait défiler le rang |
| **Libre** | générique | six caractéristiques et compétences par défaut, **entièrement configurables** |

## Le système Libre : configurez vos propres caractéristiques

Sur une campagne « Libre », le bouton **🎲** du gestionnaire ouvre l'éditeur
de système : le MJ y définit **ses** caractéristiques (libellés courts, ex.
PHY, AGI…) et **ses** compétences (chacune rattachée à une caractéristique).

- la configuration s'applique **immédiatement** à toutes les fiches de la
  campagne, chez tous les joueurs (temps réel) ;
- supprimer une caractéristique ne détruit rien : les compétences sont
  rattachées ailleurs et les scores devenus orphelins sont simplement ignorés ;
- une fiche créée ensuite naît avec les bonnes caractéristiques à 10.

<Tip>
  De quoi jouer à peu près n'importe quel JdR « à caractéristiques + d20 »
  sans attendre un module dédié.
</Tip>

## Notes de mise à jour (auto-hébergement)

Le binaire migre sa base **automatiquement** au démarrage (campagne par
défaut, clés par campagne…). Sur l'édition Supabase, appliquez les migrations
SQL du dossier `supabase/migrations` dans l'ordre — l'en-tête de chaque
fichier précise quand l'appliquer.
